プライバシーポリシー

制定日: 2026年10月（公開日に確定します） ・ 運営者: SQuidLite3 開発者

1. 基本の考え方

SQuidLite3（以下「本ツール」）は、記録の取得・保存・計算をすべて利用者の端末の中で行います。運営者はサーバーを持たず、利用者の記録、任天堂のアカウント情報、認証のための情報を受け取りません。

2. 本ツールが端末の中で扱う情報

  • イカリング3から取得した対戦・バイト・各種記録と、その画像。
  • 任天堂のサービスに接続するための認証情報（セッショントークンなど）。パスワードは本ツールに入力しません。ログインは任天堂の画面で行います。
  • 利用者が付けたタグやメモ。

これらは、利用者が選んだ保存先フォルダ（または端末の中）に保存されます。保存先がクラウドの同期フォルダ（Google ドライブ、iCloud Drive、OneDrive など）の場合、その内容はそのクラウドの運営会社の規約とプライバシーポリシーに従って扱われます。

3. 本ツールが通信する先

  • 任天堂のサーバー: 記録の取得と認証のため。
  • 認証を助ける第三者のサービス: 本ツールは認証に nxapi というオープンソースの部品を使います。nxapi は、任天堂のアプリへ接続するときに必要な一時的な値を作るため、nxapi の設定で選ばれる第三者のサービス（imink など）へ、認証の途中で使う情報の一部を送ります。どのサービスを使うかは nxapi の設定で決まります。
  • 画像の配信元: 記録に含まれる画像を、任天堂のドメイン（およびアルバム写真の配信元）から取得します。
  • 運営者のサーバーへは通信しません。利用状況の計測（アクセス解析）も行いません。

4. このウェブサイト（sql3.ink）

このサイトは Cloudflare のサービスで配信しています。配信のため、Cloudflare がアクセスの記録（IP アドレスなど）を処理することがあります。運営者はアクセス解析やクッキーによる追跡を行いません。

5. Google のサービスとの連携

本ツールには、利用者自身の Google ドライブへ記録を書き出す機能があります。この機能は、利用者が自分で許可した場合にだけ、利用者自身の Google ドライブの中で、本ツールが作るフォルダとファイルの読み書きのために Google の API を使います。Google から受け取った情報を、運営者や第三者に送ることはありません。広告や分析にも使いません。

SQuidLite3's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data accessed through Google APIs stays in the user's own Google Drive and on the user's own device, and is never transmitted to the developer or any third party.

6. 情報の削除

本ツールが保存した情報は、利用者の端末と保存先フォルダにだけあります。保存先フォルダを削除すれば、すべて消えます。運営者の手元には残りません。

7. 改定

このポリシーを変えるときは、このページで知らせます。

8. 問い合わせ

GitHub の Issues で受け付けます。
