# SQuidLite3 ロゴ（叩き台）

前田さんの依頼（2026-10-05）: 「ロゴが必要なので、暇な時にイラレで作っておいてくれ。何案かあるといいね。」

`SQuidLite3_logo_draft3.ai`（Illustrator 30.5.1）に4案。`make_logo_draft3.jsx` はそれを作るスクリプト。

- A 墨だまりのデータベース: データベースの円筒の底から、イカの足のように墨が垂れる。
- B イカのQ: 目のある Q の尾が、曲がるイカの足になる（虫眼鏡にも見え「記録を探す」の含み）。
- C データのイカ: ひれのある尖った頭のイカ。頭の2本の線で3層（データの段）を表す。
- D アプリのアイコン: 角丸の正方形に SQ3 と墨のしずく。

色は NOAHS の大辻ブルー #2A0063、金 #BD9A45、乳白 #FFFFF5、紙 #FBF5EC。文字は FuturaPT Bold / Heavy（Adobe Fonts。ロゴへの使用可）をアウトライン化。Splatoon の書体など任天堂の素材は使っていない。

既知の粗（案を絞ってから直す）: B と C の足の付け根の角が少し見える。A の段の線の端に小さな鉤が出る。
