# SQuidLite3 ロゴ

前田さんの依頼（原文は開発ログ）: ロゴを Illustrator で何案か。略称は「SQL3」。「SQL3」の文字の意匠を組み合わせる。「SQ／L3」と折り返してよい。書体は Futura でよい。

## 現行の案（第10稿、`SQuidLite3_logo_draft10_Futura.ai`、作成スクリプト `make_logo_draft10_Futura.jsx`）

第8稿で、下段「L3」を上段の中央に置いた（前田さん「下段が左に偏ってる」）。上段の幅は S と Q の丸で測り、Q の尾は含めない。第9〜10稿で、B と C の足を 3 から離し、重なるところは 3 を手前・足を奥にした。

書体は FuturaPT Bold（Adobe Fonts。ロゴへの使用可。NOAHS のワードマークと同系）をアウトライン化。「SQ／L3」の2段組み。色は大辻ブルー #2A0063、紙の上の金 #9A7A2E（紙とのコントラストのため濃い金）、大辻ブルーの上の金 #BD9A45、乳白 #FFFFF5、紙 #FBF5EC。イカの要素は Q だけに置き、スプラトゥーンのイカの形や任天堂の素材には似せない。

- A Futura の Q: Futura の字形そのまま。
- B イカの Q: O の中に目、尾を2本の細る足に。
- C 丸まる一本足: 尾を一本の足にして先を巻かせ、金のしずくを添える。
- D 墨のしずく: 尾を金の墨のしずくにする。

各案の画像（`draft10_*.png`）は、紙の上のマーク、正式名との横組み、アプリのアイコン（300・64・32）を並べたもの。
